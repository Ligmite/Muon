# Muon Shaders

**Muon** is a gameplay-focused Iris shader pack built around a physically based
raster path with an optional screen-space path tracer, a layered volumetric
cloud system, a physical atmosphere, and native HDR output.

Version **1.0.0 "Ion"** · Minecraft 1.17 – 1.21 · Iris 1.7+ · MIT licensed

![status](https://img.shields.io/badge/status-release--candidate-orange)

> Muon is a fresh codebase written for this project. It was informed by reading
> open shader packs (especially Photon, which explicitly permits studying its
> source) but contains no copied code from any pack, and **no code at all** from
> SEUS PTGI HRR 3, whose licence forbids derivative work. See `CREDITS.md`.

---

## What it does

| Area | Implementation |
| --- | --- |
| Shading | Deferred PBR: GGX + height-correlated Smith, multi-scatter energy compensation, labPBR, normal maps, POM |
| Shadows | Distorted shadow map, PCSS soft shadows, screen-space contact shadows, cloud shadows |
| AO | GTAO (horizon based) and SSAO, half resolution, depth-aware |
| Reflections | Screen-space reflections with thickness test + binary refinement, analytic sky fallback |
| Path tracing | Toggleable 1–3 mode screen-space path tracer: RT reflections → RT GI → full PT, temporally accumulated and denoised |
| Volumetrics | Half-res raymarched fog and light shafts with shadow-map visibility and HG phase |
| Clouds | Four independent volumetric layers: cumulus, cumulus congestus, altocumulus, cirrus |
| Sky | Rayleigh + Mie single scattering, sun/moon discs with limb darkening and phases, stars, galaxy, aurora, rainbows |
| Water | Analytic wave normals, refraction, Beer–Lambert absorption, caustics, SSR, edge foam |
| Post | TAA, FXAA, CAS, bloom, DOF, motion blur, exposure, filmic tonemap, warm vibrant grade, vignette, grain, chromatic aberration |
| Output | Linear Rec.709 working space, sRGB or **HDR** via rrtt217's HDR mod |
| Mods | Distant Horizons, Voxy, (Vitrail: designed-for, see compatibility notes) |

The grade is deliberately warm and vibrant with a clear, non-hazy image:
fog density is low by default, bloom is subtle, and the tonemapper keeps
saturation in the highlights instead of washing them out.

## Installation

1. Install [Iris](https://irisshaders.dev/) (1.7 or newer) and Sodium.
2. Drop `Muon-v1.0.0.zip` into `.minecraft/shaderpacks/`.
3. Select **Muon** in `Options → Video Settings → Shader Packs`.

Do **not** unzip the pack.

### Recommended starting points

| Profile | Use |
| --- | --- |
| `Low` | Integrated GPUs, 1080p |
| `Medium` | Mid-range discrete GPUs |
| `High` | Default desktop experience |
| `Ultra` | High-end GPUs, 1440p+ |
| `Path Traced` | Enables `RAY_TRACING=3` with temporal accumulation |

Path tracing is expensive. On a mid-range GPU expect roughly a third of the
frame rate of the `High` profile at the same resolution.

## Feature toggles

Everything is exposed in the in-game shader options menu, grouped into
`World`, `Lighting`, `Sky`, `Clouds`, `Atmosphere`, `Water`, `Materials`,
`Reflections`, `Ray Tracing`, `Post Processing`, `Colour Grading`, `Misc`.

Highlights:

* **Ray Tracing** — `Off`, `RT reflections`, `RT reflections + GI`, `Full path
  tracing`. Bounces, samples per pixel, roughness cutoff, temporal accumulation
  limit, denoiser strength and screen-space step count are all adjustable.
* **Clouds** — each layer has its own steps, altitude, thickness, density,
  coverage, size, detail and wind settings.
* **Materials** — labPBR or legacy specular, POM (with parallax self-shadowing),
  hardcoded specular/emission/subsurface fallbacks for vanilla textures.
* **Post** — every effect can be disabled independently.

## Compatibility

| Thing | Status |
| --- | --- |
| Iris 1.7+ | Supported (required for history buffers, per-program blending, DH/Voxy) |
| OptiFine | Best effort, not tested; some features need Iris |
| Distant Horizons | Supported: `dh_terrain`, `dh_water`, `dh_generic` exist and combined-depth logic is used in AO, SSR, volumetrics, clouds and RT |
| Voxy | Supported entry points (`voxy_opaque.glsl`, `voxy_translucent.glsl`, `voxy.json`); marked experimental because Voxy's parameter ABI is young |
| Vitrail (Vulkan) | Written to be portable (no compute, no image load/store, no geometry shaders, explicit `RENDERTARGETS`), but **not yet verified**; see `docs/COMPATIBILITY.md` |
| rrtt217 HDR mod | Native: `HDR_ENABLED` switches the final pass to the mod's paper-white encoding |
| Photonics | Not integrated |
| Apple/Metal | Not supported |

Details and caveats: [`docs/COMPATIBILITY.md`](docs/COMPATIBILITY.md).

## Repository layout

```
shaders/            the shader pack itself (this is what ships)
  lib/              portable maths and rendering modules
  program/          shared vertex/fragment stage implementations
  *.vsh *.fsh       thin per-program wrappers generated by tools/gen_programs.py
docs/               architecture, features, porting, compatibility
iterations/         one archived snapshot per released iteration
release/            built zips for the GitHub release page
tools/              validators, generators and the packaging script
```

## Building

```bash
python tools/gen_programs.py      # regenerate the program wrappers
python tools/generate_noise.py    # regenerate textures/noise.png
python tools/gen_lang.py          # regenerate lang/en_US.lang
python tools/validate.py --root .    # static validation (preprocessor + arity checks)
python tools/check_identifiers.py  # undefined variable / uniform checker
python tools/build.py             # build release/Muon-v<version>.zip + archive
```

`validate.py` is not a GLSL compiler. It runs a real preprocessor over every
program, resolves includes, verifies that every called function exists with the
right argument count, checks balanced delimiters and entry points, and keeps
the slider list and translation file in sync. It catches the mistakes that
actually happen in shader development; it cannot catch type errors.
