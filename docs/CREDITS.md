# Credits

Muon is an original codebase. This file records what was *learned from* and what
was *used*, so the provenance is unambiguous.

## Reference material (studied, not copied)

* **[Photon](https://github.com/sixthsurge/photon)** by SixthSurge — read as an
  architectural reference for Iris conventions (buffer layout, settings screen
  format, Distant Horizons and Voxy integration, the HDR-mod contract). Photon's
  licence explicitly permits studying the source and redistributing modified
  portions; Muon contains no Photon code, only ideas and conventions, and its
  own implementation of everything.
* **SEUS PTGI HRR 3** — supplied by the user for reference. Its licence forbids
  using any part of its source in another work, so **no SEUS code, structure or
  asset was used**. The path tracer in this pack was written from first
  principles (screen-space traversal, NEE, Russian roulette, temporal
  accumulation). It is deliberately a different design: it shades secondary hits
  from the G-buffer instead of PTGI's approach, and it has no GI probe system.
* **Complementary / Solas / Kappa** — not read; their feature sets were used only
  as a checklist of what players expect from a modern pack.

## Techniques and public references

* GGX / Smith / Schlick BRDFs and the split-sum environment approximation:
  Karis, *Real Shading in Unreal Engine 4*; Lagarde & de Rousiers,
  *Moving Frostbite to PBR*.
* Height-correlated Smith visibility and multi-scatter energy compensation:
  Heitz, *Understanding the Masking-Shadowing Function*; Turquin,
  *Practical multiple scattering compensation for microfacet models*.
* Horizon-based ambient occlusion: Jimenez et al., *Practical Realtime
  Strategies for Accurate Indirect Occlusion* (GTAO).
* PCSS: Fernando, *Percentage-Closer Soft Shadows*.
* ACES filmic fit: Krzysztof Narkowicz, *ACES Filmic Tone Mapping Curve*.
* Khronos PBR Neutral tone mapper: Khronos Group, `pbr-neutral` reference.
* Uncharted 2 filmic curve: John Hable, *Filmic Tonemapping Operators*.
* Bloom downsampling: Jimenez, *Next Generation Post Processing in Call of
  Duty: Advanced Warfare*.
* Blue noise: Ulichney, *Void-and-Cluster Method*; the texture in
  `shaders/textures/noise.png` is generated by `tools/generate_noise.py`, not
  copied.
* Rayleigh/Mie single scattering and the Kasten–Young air mass: standard
  atmospheric optics, implemented from the equations.
* Catmull-Rom history sampling and neighbourhood clipping for TAA: common
  practice; the formulation here follows the standard TAA literature.
